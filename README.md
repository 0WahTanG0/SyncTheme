# SyncTheme — обои, виджеты и циферблат Galaxy Watch в одном стиле

Приложение для **Samsung Galaxy S25+** и **Galaxy Watch 7**: выбираете или создаёте тему на телефоне и одной кнопкой «Применить» получаете:

- **обои** рабочего стола и экрана блокировки (градиенты «Аврора», «Сияние», однотонный фон или ваше фото);
- **виджеты**: цифровые часы, стрелочные часы, дата, заряд батареи — в цветах темы;
- **циферблат на часах** в том же стиле. Он автоматически собирается на телефоне и ставится на Galaxy Watch через официальный механизм Wear OS 6 (Watch Face Push).

## Что умеет

| | |
|---|---|
| 8 готовых тем | Аврора, Закат, Океан, Графит, Неон, Лес, Сакура, Минимал |
| Своя тема | тип фона, до 4 цветов градиента, угол, затемнение, цвет цифр и акцента |
| Фото | выбираете снимок из галереи, приложение само подбирает цвета по его палитре |
| Часы | цифровые, вертикальные (часы над минутами) или стрелочные; 4 начертания шрифта; секунды; дата |
| Циферблат | тот же фон (обрезанный под круг), те же цвета и стиль часов, кольцо секунд, 2 мини-виджета (батарея и шаги, их можно поменять на часах), экономичный режим Always-On |
| «Мои темы» | сохраняйте и переключайте собственные темы |

## Требования

- Телефон на Android 12 или новее. Galaxy S25+ подходит.
- **Galaxy Watch 7 с One UI 8 Watch (Wear OS 6) или новее.** Проверить можно в приложении Galaxy Wearable: «Настройки часов» → «О часах» → «Обновление ПО». Только начиная с Wear OS 6 приложение может само устанавливать циферблаты (Watch Face Push), а старые циферблаты Google с января 2026 года больше не поддерживает.
- Часы подключены к телефону через Galaxy Wearable.

## Установка

Готовые файлы:

- `SyncTheme-phone.apk` — для телефона;
- `SyncTheme-watch.apk` — для часов.

Чтобы телефон и часы связались, оба APK должны быть подписаны **одним ключом**. Готовые файлы уже подписаны одним ключом. Если будете собирать сами, используйте ключи из папки `keystore/`.

### 1. Телефон

1. Скопируйте `SyncTheme-phone.apk` на телефон и откройте его.
2. Если установка заблокирована, временно выключите «Настройки» → «Безопасность и конфиденциальность» → **«Автоблокировщик»**. Затем разрешите установку из этого источника («Мои файлы» / браузер).
3. Установите приложение и откройте **SyncTheme**.

### 2. Часы

Google Play не может поставить приложение на часы из файла, поэтому его ставят по отладке ADB через Wi‑Fi.

**Подготовка часов** (один раз):

1. На часах: «Настройки» → «О часах» → «Программное обеспечение» → 7 раз нажмите **«Версия ПО»**. Появится меню «Параметры разработчика».
2. «Настройки» → «Параметры разработчика» → включите **«Отладка ADB»** и **«Отладка по Wi‑Fi»**.
   Часы и компьютер (или телефон) должны быть в одной сети Wi‑Fi.

**Вариант А — с компьютера** (нужны [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)):

1. На часах: «Отладка по Wi‑Fi» → **«Сопряжение нового устройства»**. На экране появятся `IP:порт` и код.
2. На компьютере:
   ```
   adb pair 192.168.1.50:41234        # IP:порт и код с экрана сопряжения
   adb connect 192.168.1.50:37515     # IP:порт с главного экрана «Отладка по Wi‑Fi»
   adb install SyncTheme-watch.apk
   ```

**Вариант Б — прямо с телефона.** Установите из Google Play приложение для установки APK на часы, например **Bugjaeger** или **Wear Installer 2**. Подключитесь в нём к часам по IP из «Отладки по Wi‑Fi» и выберите `SyncTheme-watch.apk`.

После установки отладку на часах можно выключить: она расходует батарею.

### 3. Первый запуск

1. Откройте SyncTheme на телефоне. Вверху должно быть написано «Часы на связи: Galaxy Watch7 …».
2. Выберите тему, при желании настройте её. Внизу отметьте, что применять: «Рабочий стол», «Экран блокировки», «Виджеты», «Часы». Нажмите **«Применить»**.
3. Телефон соберёт циферблат (несколько секунд) и отправит его на часы.
4. **Только в первый раз:** откройте SyncTheme на часах (или нажмите на телефоне «Открыть на часах») → **«Сделать циферблатом»** → **«Разрешить»**.

Дальше каждое «Применить» обновляет циферблат на часах автоматически, без каких-либо действий на часах. Если часы были не на связи, циферблат установится, когда они подключатся.

### Виджеты

В приложении в блоке «Виджеты на телефоне» нажмите «Часы», «Стрелки», «Дата» или «Батарея», и One UI предложит разместить виджет. Можно и вручную: долгое нажатие на рабочем столе → «Виджеты» → SyncTheme. Виджеты меняют цвета при каждом «Применить» (если отмечено «Виджеты»). Размер можно менять, текст подстраивается сам.

## Важные особенности Wear OS

- Wear OS 6 даёт приложению **один** слот под циферблат. Поэтому SyncTheme не создаёт новые циферблаты, а обновляет свой «SyncTheme».
- Включить свой циферблат автоматически приложение может **только один раз** (ограничение Google). Если позже вы выбрали другой циферблат, вернуть SyncTheme можно так: зажмите экран часов → пролистайте до «SyncTheme».
- Мини-виджеты на циферблате (по умолчанию батарея и шаги) можно поменять: зажмите циферблат → «Настроить». Ваш выбор сохраняется при смене темы.
- В режиме Always-On фон гаснет, остаются только цифры или стрелки, чтобы экономить заряд.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| «Часы не найдены» | Проверьте Bluetooth и подключение в Galaxy Wearable |
| «Часы подключены, но SyncTheme на них не установлен» | Поставьте `SyncTheme-watch.apk` на часы (раздел 2). Оба APK должны быть из одной сборки, то есть подписаны одним ключом |
| «Часам нужен Wear OS 6» | Обновите ПО часов через Galaxy Wearable |
| «Разрешите сменить циферблат» | Откройте SyncTheme на часах → «Сделать циферблатом» |
| Отказали в разрешении | Часы → «Настройки» → «Приложения» → SyncTheme → «Разрешения» |
| Время на экране блокировки поверх обоев | Это часы One UI. Их стиль меняется в «Настройки» → «Экран блокировки» |

## Сборка из исходников

Нужны JDK 17+ и Android SDK (platform 36).

```
./gradlew :mobile:assembleRelease :wear:assembleRelease
# APK: mobile/build/outputs/apk/release/, wear/build/outputs/apk/release/
```

Проверки:

```
./gradlew :buildtools:test           # все темы × стили проходят официальный валидатор Watch Face Push
./gradlew :mobile:testDebugUnitTest  # Robolectric: рендер превью, виджетов, сборка циферблата как на телефоне
```

### Как устроено

```
core/        модель темы, генератор watchface.xml (Watch Face Format), сборка и подпись APK циферблата
watchface/   шаблон циферблата (без кода): стрелки, фон и XML по умолчанию
buildtools/  генерация ресурсов шаблона и валидация (JVM, только при сборке)
mobile/      приложение для телефона: редактор, обои, виджеты, синхронизация
wear/        приложение для часов: принимает циферблат и ставит его через Watch Face Push
keystore/    ключи подписи: app.p12 — приложения, watchface.* — циферблаты (Google требует разные ключи)
```

Цепочка работы:

1. Телефон рисует фон 450×450 и превью.
2. Генерирует `watchface.xml` по теме.
3. Подставляет всё в шаблон и переподписывает APK (apksig).
4. Получает токен у официального валидатора Google (`validator-push-android`).
5. Кладёт APK и токен в Wearable Data Layer.
6. Приложение на часах получает их и вызывает `WatchFacePushManager.updateWatchFace()`.

> Ключи в `keystore/` подходят для личного использования. Если будете публиковать приложение, сгенерируйте свои.
